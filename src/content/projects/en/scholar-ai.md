An AI-powered learning platform, where I built the layer nobody sees: the backend services and AI integration that turn a student's question into a useful answer.

## The brief

AI features are easy to demo and hard to run — latency, cost, and reliability all live on the backend. Scholar AI needed a service layer that made its intelligence feel instant and dependable.

## The approach

As the backend and AI developer, I owned the path between the interface and the models: API design, data modeling, and the integration layer that carries each request to the right AI service and shapes what comes back. The guiding principle was the same one behind this site — remove everything unnecessary, so what remains works quietly.

## The result

A backend that stays out of the way. Students see answers, not infrastructure — which is exactly how it should be.
